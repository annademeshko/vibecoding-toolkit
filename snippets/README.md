# Snippets

Рабочие фрагменты кода без общего build-процесса. У каждого файла — ясное название и примеры использования.

- `css/edge-fade.css` — мягкое затухание краёв горизонтальной ленты (без JS)
- `css/motion-tokens.css` — базовые токены осмысленных переходов и reduced-motion
- `react/useReducedMotion.ts` — SSR-friendly hook для `prefers-reduced-motion`
- `swiftui/PressFeedbackStyle.swift` — тактильный отклик на нажатие с поддержкой Reduce Motion

Сниппеты — отправные точки, проверяйте соответствие вашим проектным токенам и доступности.
