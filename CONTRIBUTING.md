# Как добавлять материалы

## Скилл

`skills/<slug>/SKILL.md` + `references/` и `agents/`, когда это нужно. Укажите, когда скилл активируется, какие задачи решает, порядок действий и чек-лист проверки. Если адаптация чужого материала — авторство и лицензия обязательны.

## Сниппет

`snippets/<stack>/<clear-name>.<ext>`. Добавьте комментарий с назначением, зависимостями и примером использования. Не коммитьте минифицированные библиотеки и ключи API.

## Промпт

`prompts/<task-name>.md`. Начинайте с цели, входных данных, ограничений и критериев готовности. По возможности избегайте неопределённых формулировок вроде «сделай красиво».

## Pull request checklist

- [ ] Воспроизводимая задача и понятное название
- [ ] Нет реальных персональных данных и секретов
- [ ] Текст и код читаемы
- [ ] Указано происхождение сторонних материалов
- [ ] Проверены поведение и доступность, где применимо
- [ ] README или каталог обновлены
