How it works

The wavefront follows the page's scroll position, creating two reversible transitions between light and dark. A WebGL shader blends nine color stops along the curve, giving the light its soft, dimensional edge.

The first frame is completely dark. Light only appears as scrolling begins. A Canvas 2D fallback is included for browsers without WebGL.

Quick start

// One accent changes the full flare. const flare = new FlareScroll( document.querySelector('canvas'), { colors: { dark: '#000000', accent: '#ED5C9C', light: '#FFFFFF' }, softness: 1.25, crest: 1.00 } ); // Scroll progress: 0 → 1. flare.setProgress(progress);
