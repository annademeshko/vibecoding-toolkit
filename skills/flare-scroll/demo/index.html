What you're seeing

A signed-distance wavefront travels vertically through two pinned scenes. The gradient follows that curve, not the screen axis. A WebGL fragment shader renders nine overlapping color stops with adjustable softness. Scroll position determines every frame, in both directions.

The initial frame is completely dark. The light appears only after the user begins scrolling. A small Canvas 2D fallback is included for browsers without WebGL.

Quick start

// One accent changes the entire flare. const flare = new FlareScroll( document.querySelector('canvas'), { colors: { dark: '#000000', accent: '#ED5C9C', light: '#FFFFFF' }, softness: 1.45, crest: 1.10 } ); // 0 → 1, driven by your scroll timeline. flare.setProgress(progress);
