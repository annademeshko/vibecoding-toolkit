## Workflow

1. Read live authoritative search-engine guidance where web access is available; date any research.
2. Inventory indexing, sitemap, canonicals, robots, heading hierarchy, accessibility and metadata.
3. Assess content usefulness, firsthand evidence, structured data validity and topical authority.
4. Separate verified crawling/ranking changes from unproven AI-citation claims; never promise ranking.
5. Prioritize fixes by impact and effort, with clear technical and content owners.

## Deliverable

Evidence-backed audit, prioritized fixes, safe JSON-LD recommendations and measurement plan.
