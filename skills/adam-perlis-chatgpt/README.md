# Adam Perlis → ChatGPT Toolkit

23 independent skill adaptations for ChatGPT and Codex. Source directory: https://adamperlis.com/skills/.

This is not an official Adam Perlis distribution and does **not** automatically install Adam's native Claude marketplace, Walkie app, or Omarchy widget. The bundle contains 6 foundational workflows, 3 UI-motion workflows, 2 brand/3D integration workflows, and 12 video-production workflows. The skills are actionable instructions, not compiled shader engines or editing applications.

## Tool routing

- In ChatGPT, use available browser/search, code tools, GitHub, Figma, video editing and file tools as supported; do not make up their availability.
- The original Walkie MCP requires a Walkie account and an authorized MCP connection; `walkie-voiceover` falls back to a script if narration is not connected.
- The original Omarchy Walkie plugin is an Arch/Omarchy system-bar widget and is **not** a ChatGPT skill; use https://github.com/adamperlis/omarchy-walkie only on supported Linux systems.
- `companion-bot-integration` describes how to integrate the *original* assets when separately obtained. This bundle intentionally excludes Adam's character/source files and Gaia's reserved brand artwork.

## Priority rules

Exact references and the project's own design system win over generic visual suggestions. For UI tasks pair this bundle with `product-ui-craft`, then with `design-constraints`, and add `frontend-design-director` for marketing/portfolio work or `awwwards-motion`/`ui-motion` for effects. Use `fullstack-coding` for implementation and verification.
