# Skills

Одна папка на один скилл. В каждой папке должен быть `SKILL.md` с YAML frontmatter (`name` и `description`). Дополнительные справочники хранить в `references/`, а настройки агентов — в `agents/`.

| Skill | Назначение |
|---|---|
| [Product UI Craft](product-ui-craft/SKILL.md) | Figma, iOS, UI audit, визуальная точность, дизайн-системы и motion |

Для сторонних/адаптированных навыков обязательно сохранять лицензию и авторство.
