# Web UI QA

- [ ] Проверены мобильная, планшетная и десктопная ширины
- [ ] Реальные шрифты и ассеты загружены, нет layout shifts
- [ ] Контент и навигация работают с клавиатуры
- [ ] Контраст и focus-visible заметны
- [ ] Light/dark mode и prefers-reduced-motion работают, если применимо
- [ ] Hover/active/disabled/loading/error состояния осмысленны
- [ ] Анимация не мешает чтению и не нагружает CPU без необходимости
- [ ] Нет неподтверждённых обещаний и фиктивных метрик
- [ ] Визуальный результат сверен с исходным референсом
