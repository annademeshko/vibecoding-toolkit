# Product UI Craft audit

Проверь приложенные экраны как продуктовый дизайнер. Используй `skills/product-ui-craft/SKILL.md`.

Не предлагай редизайн ради редизайна. Раздели замечания на UX, visual craft, accessibility/platform и reference fidelity (если есть референс).

Для каждого замечания укажи: место на экране, наблюдаемый симптом, эффект для пользователя, severity, конкретную правку и как проверить.

Сначала определи режим (Audit-only/Polish/Unslop/Redesign), затем отсортируй правки по влиянию.
